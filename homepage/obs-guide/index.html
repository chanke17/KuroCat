OBS 直播透明桌宠与三端权限配置指南

三分钟把 KuroCat 原生 2.5D 敲键盘小猫无背景接入 OBS Studio、抖音直播伴侣与 B 站直播姬，同时涵盖游戏防误触穿透、数位板绘画同步，以及 macOS / Windows / 统信 UOS 权限排查。

方案 A · 推荐

OBS Studio 原生透明窗口捕获

透明捕获无需抠图、边缘零绿边，完整保留白色贴纸描边与半透明投影，适合 OBS Studio 28+。

Windows 10 / 11 + OBS Studio

  1. 右键桌面小猫或系统托盘里的 KuroCat 图标，打开「设置」并勾选「OBS 透明窗口捕获」。
  2. 在 OBS Studio「来源」面板点击 + → 选择「窗口采集」。
  3. 窗口选择 [KuroCat-Windows-x64.exe]: KuroCat。
  4. 采集方式选为「Windows 10 (1903 及以上)」，勾选「允许透明」并取消勾选「采集光标」即可。
提示：开启 OBS 捕获模式后，KuroCat 会自动暂停「全屏自动隐藏」，防止你切到全屏游戏或全屏 PPT 时直播间小猫消失。

macOS 12.3+ + OBS Studio

  1. 点击顶部菜单栏 KuroCat 图标 → 「设置」 → 开启「OBS 透明窗口捕获」。
  2. 在 OBS Studio「来源」中新增「macOS 屏幕采集」。
  3. 采集方式选择「应用程序窗口」，目标窗口选中 KuroCat。
  4. 如使用深色游戏/代码背景，建议在 KuroCat 设置里开启「柔和白色贴纸外描边」，轮廓在直播间里会更加立体。
权限说明：首次在 macOS 用 OBS 采集窗口，需在「系统设置 → 隐私与安全性 → 录屏与系统录音」中允许 OBS Studio。

方案 B · 全平台通用

抖音直播伴侣 / B 站直播姬绿幕模式

部分直播伴侣软件不支持直接读取 Alpha 透明窗口，切换为内置纯色绿幕（#00FF00）一键色度抠图即可完美兼容。

开启纯色绿幕与滤镜

  1. 在 KuroCat 设置中开启「OBS 绿幕模式（#00FF00）」，小猫窗口背景会瞬间变为标准荧光纯绿。
  2. 在抖音直播伴侣 / B 站直播姬中点击「添加素材 → 窗口捕获」并选择 KuroCat。
  3. 选中该图层打开「滤镜 / 抠图 → 色度键 / 绿幕抠像」，关键色选择绿色（#00FF00）。
  4. 相似度默认 350–400、平滑度 60–80 即可零锯齿抠干净。

避免绿色毛色/瞳色被误抠

  • 经典小黑猫默认荧光黄绿瞳在绿幕相似度过高时可能略微发暗，建议把瞳色切为琥珀金、宝石蓝或冰蓝，或直接使用暹罗猫 / 小豆泥 / 怪猎呆猫 / 橘白猫。
  • 也可以去 KuroCat 皮肤广场 免费下载暖色系皮肤与自定义机械键盘配色，拖到小猫身上即可实时换装。

游戏直播与数位板绘画模式最佳实践

针对 FPS / MOBA 竞技游戏与数字插画主播打磨的专属细节。

竞技游戏直播防误触

  • 完全鼠标穿透：右键菜单勾选「完全鼠标穿透（游戏防误触）」，鼠标甩枪绝不会误点小猫。
  • 随时唤回菜单：点击托盘/菜单栏图标，或 Windows 按 Ctrl + Alt + Shift + P、macOS 按住 Option 键即可唤出设置。
  • 游戏内键盘没反应：若游戏以管理员权限启动（如部分网游反作弊或客户端），右键小猫选择「以管理员身份重启」即可正常同步 WASD 与技能键。
  • 无边框窗口化：真正的独占全屏不允许任何桌面顶层窗口覆盖，将游戏改为「无边框全屏」即可在自己屏幕和直播间同时常驻。

数位板绘画自动握笔同步

  • 免配置自动识别：连接 Wacom、绘王（Huion）、XP-Pen 等数位板并落笔绘画时，KuroCat 会自动把鼠标切换为 2.5D 数位板 + 压感笔握持动画。
  • 左右手与角度对齐：支持 ±180° 自由旋转磁吸对齐，可完美贴合你直播画布的右下角或左下角构图。
  • 写代码 / 写稿直播：自带实时 KPM 与今日击键统计，并支持 3 键翘后脚、4 键摇尾巴踩键彩蛋，大幅提升观众互动弹幕率。

macOS · Windows · Linux / 统信 UOS 权限说明

所有键鼠信号仅在本机内存驱动动画，零日志、零上传，全部源码遵循 MIT 协议公开审计。

macOS 输入监控 & 首次打开

  1. 首次打开若提示「无法验证开发者」，请右键 KuroCat.app 选择「打开」并在弹窗再次确认。
  2. 前往「系统设置 → 隐私与安全性 → 输入监控」勾选 KuroCat，再从顶部菜单栏点击「重启 KuroCat」即可响应全局打字。
  3. v1.4.3 起已使用稳定证书签名，后续版本覆盖升级无需重复授权。

Windows & Linux / 统信 UOS

  • Windows SmartScreen：个人开源软件未购买商业签名证书，比对官网与 GitHub Release 的 SHA-256 一致后点「更多信息 → 仍要运行」即可。
  • 统信 UOS / 银河麒麟免密码安装：下载对应架构（amd64 / arm64）的 .tar.gz 解压后执行 bash install.sh 即可免 sudo 安装到用户目录。
  • 纯 Wayland 会话：执行一次 sudo usermod -aG input $USER 并重新登录即可开启内核级硬件监听。
